vibe-pollster · cross-country backtest

Can one model call any election?

The Knesset model, generalized and tested on past elections in six countries. Each was forecast as if it hadn't happened yet, using only what the other elections taught the model.

The short answer

Exhibit 1

Every election, forecast blind

Average miss on each list's vote share, in percentage points, for the model and for a plain average of the last week's polls. "Winner odds" is the chance the model gave the list that actually came first. Green means the model beat the plain average.

Exhibit 2

Where the model earns its keep: probabilities

Brier scores (0 is perfect, lower is better) for three kinds of question, 20 days out and from the final polls. "Plain average" reads the polls as a yes-or-no answer. The variants test what each part of the model adds.

Exhibit 3

When it says 70%, does it happen 70% of the time?

All yes-or-no forecasts (threshold calls and bloc or coalition majorities), grouped by the probability the model gave them. Points on the diagonal are perfectly calibrated; above it, the model was too cautious. Most points sit on or above the line, so if anything it hedges a little too much.

Exhibit 4

How fast polls go stale

Average miss per list of a poll average against the final result, by days before the vote. These six countries against an archive of legislative elections since 1990 in 31 countries (Jennings & Wlezien).

Using it for a new election

Write a short spec (parties, which camp each is in, seat rules) and a CSV of polls, then run one command. Error sizes come from this backtest.
